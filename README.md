# RafaFit 2.0 — publicação GitHub Pages

Aplicativo PWA leve, estático e sem conta. Os registros permanecem no armazenamento local do navegador. O código hospedado é público; **não faça upload de relatórios ou backups pessoais**.

## Publicar
1. Crie um repositório `rafafit` **público** no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório, preservando a pasta `icons`.
3. Em Settings > Pages, escolha `Deploy from a branch`, `main` e `/(root)`; clique `Save`.
4. Abra `https://SEU-USUARIO.github.io/rafafit/` após a publicação.
5. No iPhone: abra pelo Safari e use Compartilhar > Adicionar à Tela de Início.

## Dados pessoais
- O aplicativo publicado não inclui medidas pessoais de saúde.
- Importar suas medidas: no aplicativo, Ajustes > Importar backup, selecione seu arquivo privado JSON.
- Backups, relatórios e dados pessoais nunca devem ser enviados ao repositório público.
- O app não sincroniza dados entre navegadores/aparelhos.
- Trocar de domínio, apagar dados do navegador ou remover o app pode apagar registros. Exporte backups periodicamente.

## Recursos
Registros de água, proteína, refeições, creatina, whey, sono, treino e medidas; biblioteca de demonstrações vetoriais esquemáticas; exportação semanal e backup; offline após o primeiro carregamento e cache do Service Worker.

## Segurança
As animações são esquemáticas e não substituem acompanhamento presencial para ajustar postura, aparelhos e cargas.
